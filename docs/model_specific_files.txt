[HOW TO MAINTAIN]
1. Add each new model/dataset-specific path and the required migration action.
2. Mark path/behavior uncertainty as REVIEW; do not assume it has been verified.
3. Mark compatible shared logic GENERIC and remaining compatibility coupling TRANSITIONAL.
4. Update this inventory in the same Git commit as related adapter/config changes.
5. Test with a new adapter before claiming the platform is fully model-agnostic.
